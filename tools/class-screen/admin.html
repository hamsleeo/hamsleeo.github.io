板块显示与标题样式 勾选要在教室大屏显示的板块；可单独设置每个板块标题的颜色和字号

这里勾选的板块会显示在大屏上，未勾选的不显示。标题颜色留空表示跟随主题默认色；字号填数字（如 22），留空表示默认大小。

可视化布局调整 在下方预览里直接拖动板块：改位置、拉大小，保存后教室大屏自动同步

在预览里点右上角 「✎ 编辑」 → 拖板块本体移动位置、拖板块四角/四边缩放 → 点 「✓ 完成」 即自动保存到云端，教室大屏约 5 秒内同步新布局，无需再点其它按钮。下方「保存布局到大屏」仅作手动补存备用。点「重置布局」可恢复默认排布。

一周课程表 按周编辑，大屏每天自动显示当天的课；每行：科目|开始|结束

选择星期分别编辑每天的课务，保存后大屏按当天星期自动切换、每周循环。单双周课程：像第八节这样隔周不同的课，科目写成 单周科目/双周科目（如 道德与法治/心理健康），大屏会按「基础信息 → 单双周基准」里设置的「本学期开学日」自动选课，标题显示「单周/双周」。每学期开学初记得更新那个日期。
晚自习：晚自习就当普通一节课写在课表最后两行，同样支持单双周——科目写成 单周科目/双周科目。注意：单双周两边都要写全类名（如 晚自习一 数学/晚自习一 物理|19:00|19:40、晚自习二 英语/晚自习二 化学|19:50|20:30），若只写 晚自习一 数学/物理，双周会只显示「物理」而丢掉前缀。若两节固定不轮换，直接写 数学|19:00|19:40 即可。大屏只显示科目、按开学基准自动切换并打「单周/双周」角标，到点自动进入「进行中」。

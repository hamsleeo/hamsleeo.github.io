班务大屏 · 音色自检

请在教室大屏所用的 Edge 浏览器中打开本页。页面会列出浏览器真正可用的在线自然音色， 并逐个显示“选择该音色时实际会播放哪一个”。点【试听】即可确认。
如果列表为空或显示“未找到”，说明当前浏览器/网络没有加载微软在线神经音，此时大屏会保持安静，不会播放机械音。 请使用教室大屏所用的 Edge 浏览器打开本页复测。

当前浏览器不是 Microsoft Edge。 微软在线神经音只在 Edge 中提供，这里检测到“未找到”属正常现象， 不代表教室大屏也如此。安装包启动的是 Edge（独立配置），请用大屏上的 Edge 打开本页复测。

音源方案说明

喊话只使用一种在线人声：微软 Edge 神经音（晓晓、云扬、晓伊、云希、云健、晓北）。 它走 Edge 浏览器自带服务，教室端安装包已强制使用 Edge，联网即可用。
原先的百度、有道备用接口和本地机械音已彻底移除：百度在部分网络连不上、有道接口已下线（返回 500）、机械音刺耳。
现在只有所选的那一种神经音在播；万一检测不到神经音（非 Edge 或未联网），大屏会保持安静，绝不叠加第二种声音。

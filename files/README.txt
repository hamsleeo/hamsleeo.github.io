教师工具箱 · 安装包存放目录

这里放随站点一起发布的软件安装包。后台「软件管理」里下载地址填 files/文件名 即可。

约定（请务必遵守）：
1. 单个文件不要超过 100 MB。超过 GitHub 会拒绝推送，几百 MB 的请改用网盘（蓝奏云 / 微云），
   把地址填到后台的「备用链接」里。
2. 整个仓库不要超过 1 GB。仓库越大，每次推送越慢，Pages 部署也越容易失败。
3. 文件名只用英文、数字、连字符，不要空格和括号，例如 wps-office-12.1.exe。
   中文文件名在部分浏览器下载后会变成乱码。
4. 本站是公开静态站点：任何拿到链接的人都能下载这里的文件。
   不要放含师生个人信息、校内内部资料、未获授权的商业授权版本。
5. 软件版权归各自厂商所有，请优先从官方渠道获取安装包；本站仅做校内教学办公的集中登记。

目录里请不要放临时文件、压缩包内嵌的破解补丁或注册机。

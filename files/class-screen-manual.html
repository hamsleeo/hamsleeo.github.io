5 分钟快速上手

第一次用？按这五步走，马上见效。

登录后台。用手机或电脑浏览器打开管理端网址，第一次使用点「首次注册」，用手机号 + 验证码注册并设置密码。首位注册人会自动成为管理员。
等分配班级 / 选好班级。普通班主任注册后需管理员在「班级与权限」里把你设为某班班主任；分配后在顶部「班级」下拉框选中自己的班级。
先建学生名单。进入「班级管理 → 学生」，用批量导入一次贴入全班姓名（每行一个），这是点评和点名的基础。
填每日展示内容。在「班级管理」里把课程表、今日作业、值日安排按格式填好并保存，大屏约 5 秒后自动更新。
试着喊一次话。进入「教室喊话」，输入「请同学们准备好课本」，点「立即喊话到大屏」——大屏立刻弹窗并用真人音色朗读。
✓ 记住一句话
所有修改都在后台（管理端）完成，教室大屏不用手动操作，它会自动同步。你只管在手机上改。
◇

认识这套系统

两套界面、两种角色，数据实时打通。

大屏（展示端）

装在教室电脑上，整屏展示课程、作业、值日、积分、榜样、公告等。已装成软件版本：开机自启、作为桌面壁纸运行，桌面图标照常可用。

管理端（后台）

你在手机或电脑上打开，负责改内容、喊话、点评、查积分。网址是在大屏网址后面加 admin.html。

两种角色

角色能做什么
管理员拥有全部权限，额外多一个「班级与权限」菜单：可新建班级、给老师分配班级和角色、删除或恢复班主任注册信息。首位注册人自动成为管理员。
班主任管理自己班级的全部日常功能（喊话、点评、积分、工具、班级内容），但看不到「班级与权限」菜单，也不能改别的班。
ⓘ 多班隔离
每个班有独立的「班级代码」（如 main、class2）。大屏和后台靠班级代码对应到同一个班，班主任只能管理被分配的班级，互不干扰。

访问地址

大屏与管理端在同一站点，示例（请以安装人员实际发给你的网址为准）：

大屏展示： https://www.smartlearner.top/tools/class-screen/index.html?class=班级代码 管理后台： https://www.smartlearner.top/tools/class-screen/admin.html?class=班级代码

其中 class= 后面的就是班级代码；班主任在后台顶部「班级」下拉框切换即可，一般不用手动改网址。

登录与账号

管理端提供三种登录方式，按需选择。

方式适用场景操作
首次注册第一次使用、还没有账号填姓名 → 手机号 → 获取验证码 → 设置密码（至少 6 位）→ 再输一次 → 点「注册并登录」。首位注册人自动成为管理员。
密码登录已设置过密码，日常最常用输入 11 位手机号 + 密码 → 点「登录」。
验证码登录忘记密码 / 没设密码输入手机号 → 点「获取验证码」→ 填入短信验证码 → 点「登录」。
⚠ 注册后看不到内容？
普通班主任注册成功后，如果还没被管理员分配班级，会看到「等待管理员分配班级」的提示。这是正常的——请联系管理员在「班级与权限」里把你设为某班班主任，然后刷新本页即可。若账号被移除，会显示「账号已被管理员移除」。

登录后在右上角可以看到当前身份、连接状态（显示已连接即表示与云端和大屏同步正常）和班级选择框。

教室电脑与悬浮控制台

大屏已经是桌面软件，不用每天开浏览器。

  • 开机自启：教室电脑开机后，大屏自动启动并以「真壁纸」方式铺满屏幕，同时桌面图标照常可以点击，不影响老师用电脑。
  • 画面刷新：大屏内容每 5 秒自动刷新一次；你在后台改的内容很快就能看到。喊话语音是实时的，不受 5 秒影响。
  • 悬浮控制台：屏幕顶部中间有一条小横条，始终浮在最上层，这是你操作大屏的开关。

悬浮控制台怎么按

单击（轻点一下）

进入「壁纸态」——大屏透明收起，看到并操作桌面图标。适合临时用电脑处理别的事。

长按约 0.6 秒

回到「前端态」——大屏重新全屏显示，可正常查看和操作。看完想回桌面再单击即可。

ⓘ 大屏顶部的按钮
在大屏右上方还有三个按钮：✦ 快捷点评 直接在屏幕上给学生加减分、✎ 编辑 调整卡片顺序和显示模块、⛶ 全屏显示。日常一般用不到，需要时点一下即可。
✓ 稳定提示
只要软件正常装好，老师不需要每天开关机操作大屏。若长时间未更新，先看右上角是否「未连接」，检查教室电脑是否联网。

ⓘ 六维是哪六维

教室喊话

老师手机输入文字，大屏立刻弹窗并用真人音色朗读——最常用的功能。

操作步骤

在后台左侧点「教室喊话」。
在「喊话内容」里输入要讲的话（最多 120 字），也可以点下方的快捷短语快速填入。
按需设置：显示时长、音色、语速、是否语音朗读。
点「立即喊话到大屏」。约几秒后大屏弹出喊话横条并开始朗读，下方进度条走完自动收起。

选项说明

选项说明
显示时长8 秒 / 12 秒 / 20 秒 / 30 秒 / 1 分钟 / 2 分钟（默认）。长通知可选 2 分钟。
音色微软在线真人音色（导航播报同款）：晓晓（温柔女声）、云扬（专业男声）、晓伊（甜美女声）、云希（阳光男声）、云健（沉稳男声）、晓北（东北话）。
语速舒缓 / 标准（默认）/ 轻快。
语音朗读默认勾选。取消勾选则只弹文字、不发声。
⚠ 关于语音的三个要点
  • 真人音色需要联网，教室电脑请保持网络畅通；网络异常时大屏会保持安静，不会改用难听的机械音。
  • 大屏用 Edge 浏览器渲染时语音效果最佳（软件版已按此配置）。
  • 浏览器为防自动播放，首次可能提示「点一下屏幕开启语音」。在大屏上点一下即可解锁；软件版已做自动解锁处理，通常无需手动。

下方「最近喊话」会保留历史记录，方便回看发过什么。

行为点评与积分

给学生加减分，一次可选多人、批量处理，结果自动上大屏。

点评四步

选学生。可搜索姓名/学号，支持「全选 / 清空」。可一次选多名学生，给他们加同样的分。
选加还是减。点「＋ 加分」或「－ 扣分」切换模式。
选行为和分值。先点六维中的一个维度，再点具体行为细则（如「主动回答 +2」「课堂讲话 -2」）；分值也可在「班级管理 → 行为细则」里自定义。
填补充说明（可选）→ 点「确认点评并同步大屏」。大屏积分、榜单、流水随即更新。
ⓘ 常用行为细则示例（可自行增删）
维度加分示例扣分示例

下方「最近流水」显示每一次加减分记录，点「↶ 撤销上一条」可以撤回刚提交的点评，方便纠正误操作。

✓ 小组分怎么来
给属于某小组的学生点评时，学生个人分与该组积分会同步变化，大屏「小组积分榜」自动更新。先在「班级管理 → 小组」把学生分好组即可。

积分统计

数据全部来自日常点评流水，无需另外录入。顶部可切换三种视图：

  • 个人总榜：全班学生按积分排名。
  • 小组总榜：各学习小组按积分排名。
  • 维度概览：六维成长画像，展示全班各维度平均分，与大屏雷达图是同一份数据。

页面下方还有「近七日积分走势」，用于观察班级一段时间的变化趋势。期末评优、班会表扬时可以直接参考这里。

教学工具

三个课堂常用小工具，都免费。

随机点名

从全班在册学生中随机抽取，点「开始点名」滚动、点「停止」定格。可点「把结果喊到大屏」直接通知全班。

课堂倒计时

设定分钟数后开始，支持暂停/重置。勾选「结束时喊话提醒」，时间到会自动喊话提示。

考勤登记

选好学生后标记为出勤 / 迟到 / 请假 / 缺勤，点「保存今日考勤」。顶部显示今日日期与汇总。

ⓘ 小技巧
点名和考勤都依赖「班级管理 → 学生」里的名单。名单越完整，工具越好用。

管理员专区

只有管理员能看到「班级与权限」菜单。普通班主任可跳过本章。

新建班级

填「班级代码」（2–32 位字母数字，如 class2）和班级名称（如「三年级二班」）→ 点「创建班级」。创建后系统会给出该班的大屏网址，把它发给该班班主任即可。

班主任与授权

老师注册后，在这里找到对应手机号，设置角色（管理员 / 班主任）、分配所属班级。分配后该老师刷新后台即可管理对应班级。

已删除的班主任

若删除了某位班主任的注册信息，他会出现在这里；需要恢复时在此操作，让其能重新注册。

⚠ 权限变更要谨慎
移除班主任会立即影响其管理权限。变更前请确认，避免误操作影响正常教学。

常见问题

遇到问题先看看这里，多数都能自己解决。

后台显示「未连接」/ 大屏内容不更新？
先确认教室电脑联网正常、大屏软件在运行。内容保存后约 5 秒刷新；如果一直「未连接」，检查网络或重启大屏软件（在桌面长按悬浮控制台调出大屏确认状态）。
喊话没有声音？
真人音色需要联网，请保持教室电脑联网。首次若提示「点一下屏幕开启语音」，在大屏上点一下即可。系统只使用在线真人音色，网络异常时会保持安静，不会换成机械音。另外确认后台「语音朗读」已勾选。
收不到短信验证码？
确认手机号填写正确、信号正常，稍等片刻再点「获取验证码」；注意查收短信拦截。仍不行可改用已设置的密码登录。
注册后看不到班级内容 / 显示等待分配？
普通班主任需要管理员在「班级与权限」里把你设为某班班主任。联系管理员分配后，刷新后台页面即可。若顶部有多个班级，记得在「班级」下拉框选中自己的班。
大屏挡住了桌面图标怎么办？
单击屏幕顶部中间的悬浮控制台进入壁纸态，即可看到并使用桌面图标；用完再长按约 0.6 秒让大屏全屏显示回来。
学生名单 / 行为细则填了但大屏没变？
文本类内容要点对应的「保存并同步到大屏」按钮才生效；学生、小组、行为细则改动后，可再做一次点评触发数据刷新，约 5 秒后大屏更新。
点评加错分了？
在「行为点评 → 最近流水」点「↶ 撤销上一条」即可撤回刚提交的点评。
数据会丢失吗？收费吗？
数据保存在云端，联网即可访问。本系统为免费版，无任何收费项目、会员或内购。重要名单建议自己在后台留存一份原始表格备份。
